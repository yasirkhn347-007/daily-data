# Distributors Account App: update karne ka tareeqa

## Ek baar (app.py badalna)
1. GitHub par `daily-data` repository kholein.
2. **Add file** > **Upload files** dabayein, naya `app.py` drag karein (purani khud replace ho jayegi).
3. **Commit changes** dabayein. 1 se 2 minute mein app update ho jayegi.

## Roz ka kaam
1. App ka link kholein, ADMIN password se login karein.
2. Left side (mobile par upar teer ">" se) mein apni Distributors Excel file (.xls ya .xlsx) upload karein.
3. "File process ho rahi hai" likha aayega. 1 se 2 minute intezar karein, phir "File upload ho gayi" aa jayega.
4. Naya data purana replace kar deta hai.

## Users ke liye
- Link aur USER password dein.
- **Distributor Summary** tab: sab parties, search ke saath.
- **Party Statement** tab: party chunein ya naam likhein, uska poora statement nazar aayega.

## Note
Free hosting par app restart ho jaye to data chala jata hai. Aisa ho to bas file dobara upload kar dein.
